# AIM (AIM Intelligent Machines)

> AIM builds autonomous earthmoving for mining, construction and defense. A plug-and-play
> retrofit kit converts existing heavy equipment — excavators, bulldozers, haul trucks — into
> self-operating machines regardless of make, model, size or age while preserving the OEM
> warranty, combining rugged onboard hardware and 360-degree camera perception with a
> tablet-based control interface and a "Site Intelligence" analytics dashboard for remote
> fleet tasking, terrain mapping and productivity reporting.

IMPORTANT FOR AGENTS: AIM publishes **no public API, SDK, developer portal, or machine-readable
contract**. As of 2026-09-14 there is no OpenAPI, AsyncAPI, GraphQL schema, MCP server, A2A agent
card, or `/.well-known/` discovery document on any host it controls, and no GitHub organization.
The docs, api, developer and app subdomains of aim.vision do not resolve. This file is generated
by API Evangelist from the public profile; it is not published by AIM.
